# ⚡ Everyone AR Beam (エブリワン AR ビーム)

Webカメラで撮影した手や指先（MediaPipe Hands）を認識し、指先から3D空間へ向かって光の柱（ARビーム）が滑らかに延長・追従するWebアプリケーションです。

## 🌟 主な特徴・機能

- **MediaPipe Hands リアルタイム追従**: 手の21個の関節・指先（ランドマーク）を認識し、指先をピンポイントでロックオンします。
- **3D空間へのビーム延長**: 指の向き・関節角度を分析し、指先が向いている方向へ向かって立体的な3Dビームが真っ直ぐ突き抜けます。
- **高速フレームレート & パーティクル描画**: Three.js (WebGL) により、指先の着弾点からリアルタイムで光のスパーク粒子が飛び散ります。
