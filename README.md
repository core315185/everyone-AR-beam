# ⚡ Everyone AR Beam (エブリワン AR ビーム)

カメラ映像内の手の形（MediaPipe Handsによる指先のランドマーク検出）を認識し、指先から3D空間へ向かって力強く光の柱（ARビーム）が延長・追従するWebアプリケーションです。

---

## 🚀 起動方法

### ローカル環境で動かす場合
1. このリポジトリの `index.html` と `README.md` をダウンロードします。
2. パソコンで開く場合は、VSCodeの **Live Server** などのローカルサーバー環境で `index.html` を開いてください。
3. スマホで開く場合は、ブラウザ（Safari / Chrome）にファイルを読み込ませるか、ローカルサーバー経由のURLにアクセスしてください。

---

## 🌟 主な機能

- **MediaPipe Hands 連携**: 手の21個の関節・指先（ランドマーク）を検出し、指先（人差し指の先など）をピンポイントでロックオンします。
- **指先の向きに応じたビーム延長**: 指が向いている方向へ向かって、立体的な3Dシリンダービームが真っ直ぐ突き抜けます。
- **3Dパーティクルエフェクト**: 指先の着弾点からリアルタイムで光の粒子が飛び散ります。
