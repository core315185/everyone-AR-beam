# ⚡ Everyone AR Beam (エブリワン AR ビーム)

カメラ映像内の人や物にタッチするだけで、リアルタイムに3D ARビームを発射・追従させるWebアプリケーションです。

特殊なアプリのインストールは不要で、スマートフォンのブラウザ（Safari / Chrome）で直接動作します。

---

## 🚀 ARを開始する

下のボタンまたはリンクをタップすると、Webブラウザで直接ARアプリが起動します。

> **👉 [ARアプリを起動する（index.htmlを開く）](./index.html)**

## 🌟 主な機能

- **ワンタップ3D発射**: 画面の任意の場所をタップするだけで、立体的な光柱（3Dシリンダーメッシュ）とロックオン照準を生成します。
- **3Dパーティクルエフェクト**: ビームの着弾点からリアルタイムで光の粒子（スパーク）が飛び散ります。
- **リアルタイム物体追従**: タップした位置の映像パターンを認識し、被写体やカメラが動いてもビームの先端が自動で追いかけます。
- **マルチビーム対応**: 画面上の複数の対象に同時にビームを固定・発射できます。
- **カメラ切替**: インカメラ / アウトカメラをスムーズに切り替えられます。

---

## 🎮 使い方

1. 上記の **「⚡ ARを開始する」** ボタンをタップします。
2. 画面中央の **「👆 タップして3D ARを開始」** をタップします。
3. カメラの利用許可ダイアログが表示されたら **「許可」** を選択します。
4. 画面上の人や物をタップすると、3Dビームが照射されます！

### 操作ボタン
- **❌ 1本解除**: 最後に発射したビームを1本削除します。
- **🗑 全削除**: 画面上のすべてのビームを消去します。
- **📷 カメラ切替**: アウトカメラ（背面）とインカメラ（前面）を切り替えます。

---

## 🛠 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **3Dグラフィックス**: Three.js (WebGL)
- **カメラ制御**: MediaDevices API (`navigator.mediaDevices.getUserMedia`)
- **トラッキング**: 階層型ブロックマッチング（オプティカルフローパターン認識）
