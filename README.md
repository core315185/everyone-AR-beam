# ⚡ Everyone AR Beam (エブリワン AR ビーム)

カメラ映像内の人や物にタッチするだけで、画面下部からターゲットへ向けてリアルタイムにARビームを発射・追従させるWebアプリケーションです。

特殊なアプリのインストールは不要で、スマートフォンのブラウザ（Safari / Chrome）で直接動作します。

---

## 🌟 主な機能

- **ワンタップ発射**: 画面の任意の場所をタップするだけで、即座に極太の光輝ビームとロックオン照準を生成します。
- **リアルタイム物体追従**: タップした位置の映像パターン（色・形状）を認識し、被写体やカメラが動いてもビームの先端が自動で追いかけます。
- **マルチビーム対応**: 画面上の複数の対象に同時にビームを固定・発射できます。
- **カメラ切替**: インカメラ / アウトカメラをスムーズに切り替えられます。
- **軽量・外部依存なし**: HTML5 Canvas (2D) ネイティブ描画を採用しているため、追加ライブラリ不要で高速に動作します。

---

## 🚀 使い方

1. `index.html` をブラウザで開くか、GitHub Pages などのWebサーバーにアップロードします。
2. 画面中央の **「👆 タップしてARを開始」** ボタンをタップします。
3. カメラの利用許可ダイアログが表示されたら **「許可」** を選択します。
4. 画面上の人や物をタップすると、ビームが照射されます！

### 操作ボタン
- **❌ 1本解除**: 最後に発射したビームを1本削除します。
- **🗑 全削除**: 画面上のすべてのビームを消去します。
- **📷 カメラ切替**: アウトカメラ（背面）とインカメラ（前面）を切り替えます。

---

## 🛠 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **描画エンジン**: HTML5 Canvas API (2D Context)
- **カメラ制御**: MediaDevices API (`navigator.mediaDevices.getUserMedia`)
- **トラッキング**: ブロックマッチングによる簡易オプティカルフロー（画像パターン認識）
