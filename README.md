# ⚡ Everyone AR Beam (AI Tip Extension Edition)

カメラ映像内の人体の先端（手や指先など）や選択した物をタップするだけで、その先端をAIが認識・追従し、**向いている方向へ向かって立体的な3D ARビームが力強く延長発射される**Webアプリケーションです。

アプリのインストール不要で、スマートフォンのブラウザ（Safari / Chrome）で直接動作します。

---

## 🚀 ARを開始する

下のボタンをタップすると、Webブラウザで直接ARアプリが起動します。

[![Start AR Beam](https://img.shields.io/badge/⚡_ARを開始する-タップして起動-00ffff?style=for-the-badge&logoColor=white)](./index.html)

---

## 🌟 主な機能

- **AI骨格・先端認識**: MediaPipe Pose AIにより、人体の関節（手首や指先）を自動検出し、ピンポイントでロックオンします。
- **3D先端延長ビーム**: タップした先端の位置を起点とし、先端が向いている方向（3次元の向き）へ向かって光の柱が力強く延長します。
- **高発光3Dエフェクト**: 立体的な3Dシリンダーメッシュ、ロックオンリング、発光パーティクル（スパーク粒子）がリアルタイムに連動します。
- **マルチビーム対応**: 画面上の複数の対象に同時にビームを固定・発射できます。

---

## 🎮 使い方

1. 上記の **「⚡ ARを開始する」** ボタンをタップします。
2. 画面中央の **「⚡ ARビームを開始」** をタップします。
3. カメラの利用許可ダイアログが表示されたら **「許可」** を選択します。
4. カメラに映る**手や指先、または物の先端**をタップすると、その位置からビームが発射され、動きに追従します！

### 操作ボタン
- **❌ 1本解除**: 最後に発射したビームを1本削除します。
- **🗑 全削除**: 画面上のすべてのビームを消去します。

---

## 🛠 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **3Dグラフィックス**: Three.js (WebGL)
- **AI・骨格検出**: MediaPipe Pose (`@mediapipe/pose`)
- **カメラ制御**: MediaDevices API (`navigator.mediaDevices.getUserMedia`)
