# ⚡ Everyone AR Beam (エブリワン AR ビーム)

Webカメラで撮影した手や指先をリアルタイムにAI認識し、指先から3D空間へ向かって力強い光の柱（ARビーム）が滑らかに延長・追従するWebアプリケーションです。

特殊なアプリのインストールは一切不要で、スマートフォンのブラウザ（Safari / Chrome）やPCで直接動作します。

---

## 🚀 アプリの起動方法

### 1. Web（GitHub Pages）から起動する（推奨）
リポジトリの設定で **GitHub Pages** を有効化すると、アプリ用URLが発行されます。

> **👉 [⚡ ARビームアプリを起動する](https://<ユーザー名>.github.io/<リポジトリ名>/)**  
> *(※ `<ユーザー名>` と `<リポジトリ名>` はご自身のGitHubアカウント・リポジトリ名に置き換えてください)*

### 2. ローカル環境で起動する場合
- **PCの場合**: Visual Studio Codeの拡張機能 **Live Server** などを使用し、ローカルWebサーバー経由で `index.html` を開いてください。
- **スマホの場合**: スマホのブラウザ（Safari / Chrome）からローカルサーバーURLにアクセスしてください。

## 🌟 主な機能と特徴

1. **MediaPipe Hands による超高精度ハンドトラッキング**:
   - 手の21個の関節・指先（ランドマーク）をリアルタイムで認識。
   - 人差し指の先端（ランドマーク #8）や親指の先（ランドマーク #4）などをピンポイントでロックオンします。

2. **指先の方向検知 ＋ 3Dビーム延長**:
   - 関節と指先の位置関係から「指が向いているベクトル」を自動計算。
   - 指の先端から空間の奥へと向かって、立体的な3Dシリンダービームが真っ直ぐ発射・延長されます。

3. **リアルタイムなフル追従**:
   - 手や指を動かしても、ビームの軸と方向がスムーズに追従し続けます。

4. **3Dパーティクル & 着弾エフェクト**:
   - Three.js (WebGL) を活用し、指先の着弾点にエネルギーリングと光のスパーク粒子がリアルタイムで舞い散ります。

## 🎮 使い方

1. アプリを起動し、**「🖐️ フル追従ARビームを開始」** ボタンをタップ。
2. カメラへのアクセス許可ダイアログが表示されたら **「許可」** を選択。
3. カメラに手をかざし、画面上の指先をタップするとARビームが発射されます！

### 操作ボタン
- **❌ 1本解除**: 最後に発射したビームを1本削除します。
- **🗑 全削除**: 画面上のすべてのビームを消去します。

## 🛠 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **3D描画エンジン**: Three.js (WebGL)
- **AIハンドトラッキング**: Google MediaPipe Hands
- **カメラアクセス**: MediaDevices API (`navigator.mediaDevices.getUserMedia`)
